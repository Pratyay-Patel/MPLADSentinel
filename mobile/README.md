# mobile (placeholder)

Reserved location for the **Flutter mobile application** used by Field Officers
for the field-verification workflow (architecture decisions D12–D13): capture
evidence, upload it to IPFS/Pinata, and send a lightweight structured metadata
payload to Spring Boot.

**Not scaffolded in the Project Foundation phase**, and not part of the Round 1
web deliverable. `Field Officer` remains a backend RBAC role, but it has no web
dashboard — field verification happens through this app.
